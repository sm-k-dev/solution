# NEXORA 기획 변경 기록

## 변경 요약

초기에는 Web Hosting, Web Security, Web Payment, SentinelOps를 포함한 종합 Enterprise Solutions 업체를 구상했습니다. Hosting과 Payment는 인프라·초기 자본, 결제사 계약·정산·인증 등 별도 사업 요건이 커 교육 프로젝트에서 구현 범위와 검증 수준을 확보하기 어렵다고 판단해 현재 범위에서 제외했습니다.

현재 프로젝트는 **Web Security와 SentinelOps를 중심으로 한 보안 전문 업체 웹 서비스**로 범위를 좁혔습니다. Security는 웹 요청과 AI 프롬프트의 위협 징후를 탐지·기록하고, SentinelOps는 서버 오류를 수집해 분류·분석·알림·대응합니다.

## 현재와 향후 범위

| 구분 | 범위 |
|---|---|
| 현재 구현 | 사이트 내부에서 웹·AI 위협과 서버 오류를 수집하고 관리자 관제 기능 제공 |
| 현재 제외 | 네트워크 방화벽/WAF 차단, 결제 처리, 호스팅 사업 운영 |
| 후속 구상 | 외부 고객이 무료·유료 구독으로 Security/SentinelOps API 사용 |
| 후속 과제 | 고객별 API 키 수명주기, 인증·권한, 사용량 제한, 요금제·결제 설계 |

REST API 엔드포인트는 추가됐지만, 이것만으로 무료·유료 구독 또는 고객별 API 상품이 구현된 것은 아닙니다.

## 기록

- **2026-10-02**: 초기 4개 솔루션 중 Web Hosting과 Web Payment를 현재 사업 범위에서 제외하고 Security·SentinelOps 중심으로 재정리.
- **2026-10-06~12**: 웹 요청·AI 프롬프트 위협 관제 기능과 외부 서비스 연동용 REST API를 프로젝트 범위에 추가.
