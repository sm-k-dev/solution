## Non-functional

| ID | 요구사항 |
|---|---|
| NFR-001 | 비밀번호를 평문 저장하지 않는다. |
| NFR-002 | DB/API 비밀정보를 Git에 commit하지 않는다. |
| NFR-003 | 주요 비즈니스 데이터는 soft delete 정책을 따른다. |
| NFR-004 | 주요 화면은 반응형 UI를 유지한다. |
| NFR-005 | DB 변경 시 SQL/ERD/문서를 함께 갱신한다. |
| NFR-006 | 개인 브랜치 + PR 방식으로 통합한다. |

실제 구현이 완료되고 테스트까지 통과한 경우에만 `DONE`으로 변경합니다.
