# NEXORA 요구사항 정의서

기준일: 2026-10-07

상태:

- `DONE`: 현재 소스에 구현 완료
- `IN_PROGRESS`: 구현 또는 보완 중
- `PLANNED`: 다음 단계 예정
- `HOLD`: 현재 제출 범위에서 보류
- `OUT_OF_SCOPE`: 기획 변경으로 제외

## 1. 기획 범위

NEXORA는 보안 전문 솔루션 업체를 목표로 하며, 현재 프로젝트의 핵심 솔루션은 Web Security와 SentinelOps입니다. 초기 기획의 Web Hosting과 Web Payment는 인프라 규모, 초기 비용, 계약·정산·인증 등 별도 사업 요건이 커서 현재 범위에서 제외했습니다.

현재 구현은 사이트 내부 관제 기능입니다. 외부 고객이 무료 또는 유료 API를 구독하는 기능은 후속 단계로 분리합니다.
