## 2. 브랜치 역할

| Branch | 용도 |
|---|---|
| `ksm`, `hw`, `sm` | 팀원별 개발 브랜치 |
| `team` | 기능 통합과 공동 테스트 브랜치 |
| `main` | 최종 제출·배포 직전 반영하는 보호 브랜치 |

개인 브랜치에서 작업하고 PR로 `team`에 반영합니다. `main`은 최종 검증이 끝난 통합본만 반영합니다.

## 3. 김순민 수행 영역

### 팀장 업무

- 프로젝트 주제와 기능 범위 조정
- 팀 의견 취합 및 일정·우선순위 조율
- 공통 디렉터리, 문서, Git 규칙 관리
- PR 확인과 `team` 통합
- DB 스키마·샘플 데이터·ERD 통합
- 전체 소스 컴파일 및 통합 테스트 자료 정리

### SentinelOps

- 처리되지 않은 Java 예외 및 HTTP 5XX 공통 감지
- 규칙 기반 Severity 분류
- Incident 목록·상세 및 관리자 대응 화면
- 상태 전이와 변경 이력
- OpenRouter 기반 오류 요약·원인·대응 분석
- CRITICAL 및 전일 요약 Slack 알림
- Incident와 Inquiry 연결·해제

### Security

- 웹 요청의 SQL Injection, XSS, Path Traversal, Command Injection, SSRF 탐지
- AI Prompt Injection, System Prompt Extraction, Tool Abuse, Jailbreak 탐지
- 민감정보 마스킹, 출처 IP 해시, 이벤트 중복 집계
- Security 이벤트 목록·상세·상태 이력
- OpenRouter 보조 분석 및 Slack 알림
- SentinelOps AI 입력에 Security 검사 연결

### 공통 통합 보완

- Inquiry 사용자·관리자 기능 연결
- Admin 대시보드와 공통 좌측 메뉴 통합
- JSP 위치 및 contextPath 링크 정리
- 공통 헤더·푸터와 CSS 일관성 보완
- 솔루션 기획을 Web Security와 SentinelOps 중심으로 변경

## 4. 이현우 수행 영역

- NOTICE, RESOURCE, FREE 게시판 목록
- 게시글 상세·작성·수정·삭제
- 댓글·대댓글
- 다중 첨부파일 업로드·다운로드
- 태그, 검색, 페이징
- 관리자 게시글 관리 연동 지원

최종 보고서에는 실제 commit과 PR을 기준으로 세부 기여 내용을 확정합니다.

## 5. 유승민 수행 영역

- 회원가입과 입력 검증
- login_id 중복 확인
- 로그인·로그아웃과 세션 생성
- 마이페이지와 활동 내역
- 회원정보·비밀번호 수정
- 회원탈퇴 시 `WITHDRAWN` 상태 변경
- 관리자 회원 관리 연동 지원

비밀번호 단방향 해시 적용은 남은 공통 보안 과제로 관리합니다.

## 6. 공동 작업

- `team` 브랜치 통합 후 기능 간 회귀 테스트
- 회원 세션과 Board·Inquiry·Admin 권한 연동 확인
- 공통 UI와 반응형 화면 확인
- 발표 시나리오, 결과보고서, 시연 데이터 준비
- 실제 비밀 설정이 Git에 포함되지 않았는지 확인
