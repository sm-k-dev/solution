## 팀장 공통 업무

- 공통 프로젝트 구조 및 문서 관리
- 팀 의견 취합과 진행 방향 조율
- GitHub 통합 및 PR 확인
- DB 및 공통 설정 변경사항 취합
- 최종 통합 테스트와 결과보고서 자료 취합

## 2차 공통 작업

핵심 담당 기능을 우선 구현한 뒤, 아래 기능은 진행 상황에 따라 팀 내에서 분담합니다.

- Inquiry(고객 문의) 기능
- Admin 기능
- 기능 간 연동 및 통합 테스트
- 결과보고서 및 발표 자료 정리
