# Repository Cleanup Checklist

현재 WAR를 Eclipse source project에 반영할 때 확인합니다.

- [ ] 루트 `README.md`를 새 프로젝트 README로 교체
- [ ] `CONTRIBUTING.md` 제거
- [ ] `SETUP_GUIDE.md` 제거
- [ ] 기존 `Git_협업_가이드.md`, `코딩_규칙.md`가 루트에 있으면 `docs/`로 이동
- [ ] `PURE_CSS_CONVERSION_README.md` 내용은 새 README/Audit로 통합 후 제거
- [ ] `docs/` 문서 추가
- [ ] `database/` v4 파일 추가
- [ ] 실제 `context.xml`이 Git에서 추적 중이면 `git rm --cached <실제경로>/context.xml`
- [ ] `context.xml.example`만 commit
- [ ] `WEB-INF/web.xml`의 `FunWeb` display-name 변경 여부 검토
- [ ] 신규 DB 적용 시 로컬 context의 driver/database를 NEXORA 기준으로 갱신
- [ ] `git status`에서 실제 비밀번호/secret 파일이 stage되지 않았는지 확인

권장 문서 정리 commit:

```text
docs: 프로젝트 문서 구조 및 개발 규칙 정리
```

DB 파일까지 함께 크게 바꾸기보다 문서와 DB를 별도 commit으로 나누는 것을 권장합니다.
