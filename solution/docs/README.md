## 문서 관리 원칙

- 구현 상태는 소스와 설정을 기준으로 기록하고, 테스트 결과는 실행 날짜와 함께 남깁니다.
- 실제 비밀번호, API 키, Webhook URL, 고객 데이터는 문서·예제·샘플에 넣지 않습니다.
- DB/API/기능 동작이 바뀌면 관련 문서와 테스트 케이스를 같은 변경에서 갱신합니다.
- 예전 상황을 기록한 문서는 현재 운영 절차처럼 쓰지 않습니다. 필요한 의사결정만 `프로젝트/기획_변경_기록.md`에 남깁니다.
