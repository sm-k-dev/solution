# NEXORA 테스트 케이스

기준일: 2026-10-06

상태:

- `PASS`: 현재 기준으로 검증 통과
- `RETEST_REQUIRED`: 과거 확인했으나 최신 통합본에서 재확인 필요
- `NOT_TESTED`: 아직 실행하지 않음
- `FAIL`: 기대 결과와 다름
- `BLOCKED`: 환경 또는 선행 조건 부족

화면이 표시되는 것만으로 PASS 처리하지 않습니다. DB 변경, 권한, 상태 이력, 외부 연동 결과까지 확인합니다.
