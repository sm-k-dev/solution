## 파일명 원칙

- 팀원이 읽고 수정하는 Markdown 문서는 한글 파일명을 사용합니다.
- GitHub 첫 화면에서 자동 인식하는 루트 `README.md`는 유지합니다.
- `.gitignore`, `context.xml.example`, `db.properties.example`, SQL 및 ERD 원본 파일명은 실행·설정·참조 호환성을 위해 유지합니다.
- `docs/`, `database/` 폴더명도 경로 안정성을 위해 유지합니다.
