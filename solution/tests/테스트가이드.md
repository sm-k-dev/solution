# Tests

각 파일은 `main` 메서드로 실행하는 간단한 회귀 점검 코드입니다.

- `SecurityDetectorCheck.java`: 웹·AI 위협 규칙과 마스킹
- `SeverityClassifierCheck.java`: SentinelOps 심각도 분류
- `IncidentStatusCheck.java`: 인시던트 상태 전이
- `IncidentAiResponseCheck.java`: AI 분석 응답 파싱
- `SlackWebhookCheck.java`: Slack Webhook 호출
- `PasswordHasherCheck.java`: PBKDF2 비밀번호 해시·검증 및 레거시 호환
- `MemberRetentionPolicyCheck.java`: 탈퇴 3개월 보유 기간 경계값 검증

외부 서비스 테스트는 실제 키나 URL을 소스에 적지 말고 환경 변수로 전달합니다. 상세 Security 실행 명령은 `docs/Security_테스트_가이드.md`를 확인하세요.
